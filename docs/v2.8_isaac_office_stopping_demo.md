> **DEPRECATED (2026-07-08) — pre-baseline material.** This document
> predates the live articulated-robot pipeline and must not be cited as
> current evidence; gates and statuses herein are historical. See
> `docs/experiments/PROJECT_BASELINE_STATUS.md` for the valid baseline.

## Purpose

This demo makes the GNM-VLNVerse stopping-reliability gap visible without
requiring the viewer to read the metrics table first.  It replays one real
Track A episode — selected automatically where the robot entered the goal
region (OSR = True) but did not stop correctly (SR = False) — inside a
lightweight Isaac Sim office scene.

## Claim boundaries

- **Visual evidence demo only.**  No paper claim is made or implied.
- **No physical Yahboom M3 Pro deployment claim.**  The demo runs in Isaac
  simulation only.
- **No Track B completion claim.**  Track B language-grounding work is
  separate and ongoing.
- **No global superiority claim.**  The demo shows baseline behaviour on one
  selected episode.
- **geometry_aware_oracle overlay is DIAGNOSTIC ONLY — not deployable.**  It
  is shown to illustrate what a perfect-information stopping rule would do,
  not as a proposed system.

## Usage

```bash
conda activate isaac

# Simplest — auto-select best OSR-not-SR episode, overview camera
python scripts/gnm/isaac_office_stopping_demo.py \
    --episode auto_osr_not_sr \
    --method baseline_gnm \
    --view overview

# All overlays, multi-camera cycling
python scripts/gnm/isaac_office_stopping_demo.py \
    --episode auto_osr_not_sr \
    --method baseline_gnm \
    --overlay temporal_stop_head \
    --overlay geometry_oracle \
    --view multi_camera

# Console-only (no Isaac Sim required)
python scripts/gnm/isaac_office_stopping_demo.py --no-isaac

# Config-validation dry-run (CI safe)
python scripts/gnm/isaac_office_stopping_demo.py --dry-run
```

| Flag | Values | Default | Description |
|------|--------|---------|-------------|
| `--episode` | `auto_osr_not_sr` \| episode_id | `auto_osr_not_sr` | Episode selection mode |

## Episode selection

`auto_osr_not_sr` reads
`results/research_audit/tracka_all_methods_per_episode_metric_provenance.csv`
and picks the episode with the smallest `minimum_distance_to_goal` among rows
where `oracle_success_flag = True` and `success_flag = False` for the
requested method.  This is the episode where the robot penetrated deepest into
the goal zone before failing to stop.

As of v2.8 the selected episode is `kujiale_0203_kujiale_0203_25_0`:

| Metric | Value |
|--------|-------|
| success_radius | 3.0 m |
| minimum_distance_to_goal | 1.40 m |
| final_distance_to_goal | 4.55 m |
| success_flag | False |
| oracle_success_flag | True |
| navigation_error | 4.55 m |

The robot came within 1.40 m of the goal but stopped 4.55 m away — a
3.15 m stopping gap relative to the closest approach.

## Overlays

### temporal_stop_head

Shows where the temporal neural stop head would have issued a stop command,
derived from the per-episode detail traces in
`results/bo_reviewer_packet/temporal_stop_head/22_temporal_stop_head_details.csv`.
Displayed as a green sphere.

### geometry_aware_oracle

Shows where the geometry-aware oracle would have stopped (at the closest
approach to the goal).  Displayed as an orange sphere.

**This overlay is diagnostic only.  It uses privileged map geometry not
available to a deployed agent.**

## Cameras

| Name | Description |
|------|-------------|
| `overview` | Angled top-down view of the full office path |
| `start_state` | Fixed camera looking at the robot start location |
| `goal_state` | Fixed camera looking at the goal region |
| `robot_pov` | Camera following the robot at head height |
| `multi_camera` | Cycles through overview → start_state → goal_state during replay |

## Trajectory note

The trajectory shown is **synthetic and representative**.  Actual XY waypoint
logs for the Kujiale Track A episodes are not stored in this repository; only
aggregate metrics (final_distance_to_goal, minimum_distance_to_goal) are
available in the provenance CSV.  The synthetic path is geometrically
consistent with those metrics: it reaches the recorded minimum distance to the
goal and ends at the recorded final distance.
